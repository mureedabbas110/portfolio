# Mureed Abbas Portfolio — V3

## Replace the old GitHub Pages portfolio
1. Extract this ZIP.
2. Open your GitHub repository: `mureedabbas110/portfolio`.
3. Click **Add file → Upload files**.
4. Upload/replace:
   - `index.html`
   - `style.css`
   - `script.js`
   - `Mureed-Abbas-CV.pdf`
   - the entire `assets` folder
5. When GitHub asks about replacing existing files, choose **Replace** / keep the new versions.
6. Commit directly to `main` with a message such as `Upgrade portfolio to V3`.
7. Wait 1–3 minutes and refresh the GitHub Pages site.

Expected site:
https://mureedabbas110.github.io/portfolio/

Important:
- Do not upload the ZIP itself into the repository.
- Upload the extracted files/folders.
- The CV is included in this V3 package and the download button points to `Mureed-Abbas-CV.pdf`.
- All image paths are relative, so GitHub Pages and mobile browsers can load them.
